Step 3

Seeding the database

  • Seeding = filling a fresh database with starting data

Bonus · Deploy 1 of 5

Push your code to GitHub

git checkout final
git remote add mine https://github.com/<you>/mini-shop.git
git push -u mine final
  • Create an empty repo on GitHub first, with no README
  • Render and Vercel both deploy straight from a GitHub repo and branch
  • .env is in .gitignore, so your database password is not pushed
Bonus · Deploy 2 of 5

The API on Render

  1. Render dashboard → New → Blueprint → pick your repo and the final branch
  2. Render reads render.yaml: build npm install, start npm run start -w server
  3. Set the environment variables below
  4. Open https://<service>.onrender.com/api/health, you should see {"status":"ok"}
VariableValue
DATABASE_URLyour Neon connection string, the same as in server/.env
CLIENT_ORIGINleave http://localhost:5173 for now

The health endpoint from step 2 is exactly what Render calls to know your app is alive.

Bonus · Deploy 3 of 5

The client on Vercel

  1. Vercel → Add New → Project → pick the repo
  2. Framework preset Vite, Root Directory = client
  3. Turn on Include source files outside of the Root Directory (the app is an npm workspace)
  4. Add the variable below, then Deploy and copy your Vercel URL
VITE_API_URL=https://<service>.onrender.com/api

VITE_ variables are baked in at build time, so change it and you must redeploy.

Bonus · Deploy 4 of 5

Close the loop: allow your site (CORS)

Remember step 2? The browser blocks any site the API has not named. Tell Render about your Vercel site:

CLIENT_ORIGIN=https://your-app.vercel.app
  • No trailing slash, or the match fails
  • Render redeploys by itself. Open your Vercel URL: the 12 products load from Neon
  • The same database now serves localhost and production. Seed once with npm run db:seed
Bonus · Deploy 5 of 5

When it does not work

SymptomLikely cause
Console says CORSCLIENT_ORIGIN is wrong or has a trailing slash
The page calls localhost:3001VITE_API_URL is not set. Set it, then redeploy the client
API returns 500Read the Render logs. Usually DATABASE_URL is wrong, or the seed was never run
First load takes a minuteFree tier cold start. The API sleeps after 15 minutes without traffic
